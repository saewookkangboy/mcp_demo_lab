# 03. 설계도 제작 MCP — 초급

## 학습 목표

- 숫자·문자 입력 스키마와 경계값 검증을 작성한다.
- MCP 결과에 SVG 같은 표시 가능한 산출물을 포함한다.
- 정상값, 경계값, 오류값의 테스트 차이를 익힌다.

## 실행과 예상 결과

`npm run dev` 후 `/projects/03-beginner-blueprint/`를 연다. 8m × 6m 교육장은 48㎡, 권장 좌석 12개와 직사각형 SVG로 표시된다.

MCP 실행 과정에서 `generate_floor_plan`의 입력 스키마와 SVG가 포함된 결과를 확인하고, 1m 치수로 오류 흐름을 시연한다.

Harness 비교에서는 면적 계산과 SVG 존재 여부가 적용 열에서 검증되는지 확인한다.

## 학습자 테스트

`node --test projects/03-beginner-blueprint/tests/app.test.js`

실습: `src/server.js`에 `출입문 위치` 인자를 추가하고 SVG의 문 위치와 테스트를 함께 변경한다.

## 실패·검증 포인트

- 2m 미만 또는 숫자가 아닌 치수: 도구 호출이 실패해야 한다.
- 20㎡ 미만: 동선 경고가 있어야 한다.
- SVG에 용도 텍스트가 포함되고 면적은 `가로 × 세로`와 같아야 한다.
- 주의: 건축·소방 기준을 반영하지 않은 교육용 개념도다.
