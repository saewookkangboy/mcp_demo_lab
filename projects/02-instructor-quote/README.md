# 02. 견적서 작성 MCP — 강사 시연용

## 학습 목표

- 사용자 입력이 도구 인자로 전달되는 과정을 설명한다.
- 금액 계산처럼 결정적인 로직은 테스트로 보호한다.
- FE 표시값과 도구 반환값을 구분한다.

## 실행과 예상 결과

`npm run dev` 후 `/projects/02-instructor-quote/`를 연다. 웹사이트 진단 2개는 공급가 300,000원, 부가세 30,000원, 합계 330,000원으로 표시된다.

MCP 실행 과정에서 `calculate_quote` 인자와 반환 금액을 비교하고, 수량 0으로 오류 흐름을 시연한다.

Harness 비교에서는 합계가 공급가와 부가세의 합인지 검증한 증거가 적용 열에 남는지 확인한다.

## 학습자 테스트

`node --test projects/02-instructor-quote/tests/app.test.js`

`src/server.js`의 가격을 변경한 뒤 테스트 기대값도 함께 바꾸며 계약 테스트의 역할을 확인한다.

## 실패·검증 포인트

- 수량 0/음수: 도구가 계산을 거부해야 한다.
- 합계: `공급가 + 부가세`와 항상 일치해야 한다.
- 주의: 실제 사업 견적이 아니며 가격·세금·유효기간은 가상 데이터다.
